# Dev Challenge Generator

A small vanilla JavaScript project that generates random programming challenges and mini-project ideas.

The goal of this project is to build a useful little tool entirely from scratch while practicing JavaScript fundamentals, DOM manipulation, and working with structured data.

## Current Status

In development — V1

The project is currently in the initial setup stage.

## Planned Features

- Random programming challenge generation
- Challenge categories
- Difficulty levels
- Estimated completion times
- Challenge filtering
- Responsive interface

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript

## Future Plans

The project may eventually grow into a platform where developers can submit their own challenges and projects, allowing others to discover ideas and see what the community built from them.

For now, the focus is simply on building a solid V1 from scratch.
